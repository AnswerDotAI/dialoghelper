ast_grep

def ast_grep(
    pattern:str, # ast-grep pattern to search, e.g "post($A, data=$B, $$$)"
    path:str='.', # path to recursively search for files
    lang:str='python', # language to search/scan
):

Use ast-grep to find code patterns by AST structure (not text).

Pattern syntax: - $VAR captures single nodes, \[$ captures multiple - Match structure directly: `def $FUNC(\]$)finds any function;class $CLASSfinds classes regardless of inheritance - DON'T include:` - it’s concrete syntax, not AST structure - Whitespace/formatting ignored - matches structural equivalence

Examples: import $MODULE (find imports); $OBJ.$METHOD($$$) (find method calls); await $EXPR (find await expressions)

Use ast_grep to find calls to an API before changing it. Patterns match multiline code and nested expressions.

ast_grep calls the ast-grep CLI to search code by syntax tree. Matches ignore formatting differences.

The pattern add_msg($A, msg_type=$B) matches calls to add_msg with two arguments:

  • Any first argument, captured as $A.
  • A msg_type keyword argument, captured as $B.
res = ast_grep(r"add_msg($A, msg_type=$B)", '..')

A pattern matches code, such as await $EXPR or console.log($ARG). A kind rule matches a syntax tree node type.

To search the entire subtree with has or inside, set stopBy: end:

has:
  pattern: await $EXPR
  stopBy: end

In shell commands, use single quotes around patterns or escape $ as \$ to prevent variable expansion.

Input

input accepts a string prompt or custom UI. Custom UI needs:

  • A <solveit-input> wrapper, which input adds automatically.
  • A POST to /input_reply_ with a value for user_input.
  • For keyboard shortcuts, an accesskey on the button and a containing form or div with ID input-request-form.
